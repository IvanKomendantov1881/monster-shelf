# Monster Shelf

Мобильная коллекция вкусов и банок Monster. Открывается по ссылке без установки, IDE и компилятора.

## Возможности

- Нажатие на банку переключает отметку «пробовал».
- Отдельная отметка «банка есть» для коллекции, в том числе неоткрытых банок.
- Поиск, фильтры по линейке, региону и отметкам.
- Добавление собственной банки с фото.
- Выгрузка и восстановление резервной копии JSON.
- Добавление ярлыка на главный экран телефона.

Данные коллекции и пользовательские фото хранятся **только в браузере посетителя**. У каждого устройства отдельная коллекция. Скачивайте резервную копию перед очисткой браузера или сменой телефона. В этот репозиторий пользовательские отметки и фото не отправляются.

## Каталог

83 региональные позиции по официальным каталогам 15 стран, проверенным 25.10.2026. Это не полный архив всех исторических вкусов, дизайнов и объёмов. Некоторые отличающиеся региональные названия и форматы оставлены как отдельные коллекционные позиции. Точные источники: `catalog.json`.

Изображения и названия принадлежат Monster Energy и соответствующим правообладателям. Проект неофициальный, коллекционный.

## Публикация

Сайт публикуется GitHub Pages из корня ветки `main`. После изменений и коммита в `main` GitHub обновляет сайт автоматически. Сборка не требуется.

Для локального просмотра достаточно любого статического HTTP-сервера в этой папке.
